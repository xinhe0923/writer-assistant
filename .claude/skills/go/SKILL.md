# /go 开工

先遵守 CLAUDE.md 的铁律：不写任何故事正文（引用我写过的原文除外），不修改 正文/ 下已有的文件。

1. 用 `git remote -v` 看有没有远程。有就运行 `git pull --ff-only`；失败就提示一句「没能同步远程，先用本地内容」，然后继续。
2. 读 断点.md。如果「位置」那一行还是模板原样（括号里的说明文字或空着），走下面的「冷启动」，不再做第 3–5 步。
3. 当前章：以 断点.md「位置」里写的文件为准；没写就用 正文/ 里编号最大的 .md 文件。只读这两样：
   - 当前章最后约 500 字（用 Read 的 offset 只读文件末尾，不要通读全文）；
   - 断点.md 里提到的人物在 设定/人物.md 中的条目。
4. 运行 `python3 tools/wordcount.py --event go --file <当前章，如 正文/001.md>`，向 日志.csv 追加一行 go（delta 为 0）。
5. 按下面的固定格式输出，总共不超过 250 字：

```
【前情】（≤150 字，只概括正文里已经发生的事）
【停在】<文件> ·「<原样引用我写的最后一句>」
【下一句开头】<断点.md 里的原文>
【这次的小任务】<一个，10–15 分钟能写完>
【不想写这个？】<备选一> / <备选二>（例如「写一段你最想写的对白」「往灵感箱丢三个画面」）
【没解决】<最多 3 条，没有就写「无」>
```

## 冷启动

1. 一次问完这 4 个问题，然后等我回答：
   1. 一句话梗概？
   2. 主角想要什么、怕什么？
   3. 结局大致方向？
   4. 第一场戏是什么画面？
2. 用我的原话整理进 大纲.md（梗概、主角、结局方向；第一场戏写进节拍 1 的「要发生什么」）。我说「没想好」的那一项，给 3 个一句话的选项让我挑，挑完再写进去。
3. 创建空的 `正文/001.md`（只创建空文件，不写任何内容）。
4. 写 断点.md：位置写「正文/001.md · 还没开始」；下一句开头留空，等我写；下一个小任务是节拍 1；更新时间写现在。
5. 运行 `python3 tools/wordcount.py --event go --file 正文/001.md`。
6. 用一句话告诉我：从 正文/001.md 开始，第一个小任务是什么。
